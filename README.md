
# Sistema de Cadastro de Produtos com Python e SQLite

## Sobre o projeto

Projeto de estudo desenvolvido para praticar conceitos básicos de Banco de Dados, SQL e programação em Python.

O sistema permite gerenciar produtos por meio de um menu interativo no terminal.

## Tecnologias utilizadas

- Python
- SQLite
- SQL
- Visual Studio Code

## Funcionalidades

- Cadastrar produtos com nome, preço e quantidade.
- Listar todos os produtos cadastrados.
- Atualizar a quantidade de um produto.
- Excluir produtos pelo ID.
- Armazenar informações em um banco de dados local.
- Validar entradas básicas do usuário.

## Operações SQL utilizadas

- CREATE TABLE: criar a tabela de produtos.
- INSERT: cadastrar novos produtos.
- SELECT: consultar os produtos.
- UPDATE: atualizar quantidades.
- DELETE: excluir produtos.

## Como executar

1. Instale o Python 3.
2. Baixe ou clone este repositório.
3. Abra a pasta no VS Code.
4. Execute no terminal:

    python cadastro_produtos.py

O banco de dados SQLite será criado automaticamente na primeira execução.

=== CADASTRO DE PRODUTOS ===

## Objetivo

Desenvolver conhecimentos iniciais em Banco de Dados e programação, praticando operações CRUD (Create, Read, Update e Delete).
